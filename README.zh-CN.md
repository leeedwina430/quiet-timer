# 静音倒计时（Quiet Timer）

一个 macOS 上的静音倒计时小工具。倒计时会一直悬浮在屏幕角落，让你随时看到剩余时间；时间到了不响闹铃，而是弹出一个提醒窗口。专为多人工位、开放式办公室设计，不会吵到身边的人。

仓库同时包含英文版和中文版。English guide: [README.md](README.md)。

## 功能

- **倒计时一直可见。** 一个半透明的小胶囊，压在所有窗口上面，包括全屏的 App。可以拖到屏幕任意角落，位置会被记住。
- **有紧迫感，但没有噪音。** 随着时间减少，胶囊从绿色变成橙色再变成红色，底部还有一条进度条。有三种大小，透明度可调。
- **静音的到点弹窗。** 屏幕中央弹出大窗口，没有任何声音。不处理它就一直在，并持续显示已超时多久。
- **想隐藏随时隐藏。** 在任何软件里按 **Control + Option + T** 即可隐藏或显示胶囊（倒计时仍在后台走），也可以在菜单里选「隐藏一会，之后自动出现」（5 到 60 分钟）。
- **设置很快。** 一键选择常用时长（10 分钟到 2 小时），也可以自己输入：`25`、`45m`、`1.5h`、`1h30m`、`90s`、`25:00`。
- **每日目标统计。** 倒计时结束时勾选「完成目标」或「未完成目标」。菜单里随时显示今天的成绩，点 **Call it a day** 可以查看完成率，并清零计数、开始新的一天。
- **轻量、隐私。** 内存占用约 25 MB，不联网，没有统计上报、没有账号，也不需要任何特殊权限。设置只保存在本机。整个 App 只有一个 Swift 文件，没有任何依赖。

## 安装

静音倒计时以源码形式发布，在你自己的 Mac 上编译。这里没有提供现成的安装包：要发布可直接打开的安装包，需要 Apple 开发者证书和公证，否则 macOS 会拦截下载来的 App。

**系统要求：** macOS 11 或更高版本，以及 Xcode 命令行工具。如果没有安装，安装脚本会触发系统的安装窗口。「开机自动启动」选项需要 macOS 13 或更高版本。

1. 下载本仓库（**Code > Download ZIP**，然后解压），或者用 `git clone`。
2. 打开「终端」，`cd` 到该文件夹，运行下面其中一条命令：

   ```bash
   bash install.sh zh     # 中文版
   bash install.sh en     # 英文版（English）
   ```

3. 脚本会编译（20 到 60 秒），安装到 `~/Applications` 并自动启动。

安装其中一个语言版本时，会替换已安装的另一个版本。更新代码后想重新编译，再运行同一条命令即可，你的设置会保留。

想手动编译：`swiftc -O -swift-version 5 -o QuietTimer src/zh/main.swift`。

## 使用方法

**开始倒计时。** 点击胶囊（刚开始显示「点击设置」），选择时长，或选「自定义…」。菜单栏里的小计时器图标也能打开同一个菜单；胶囊被隐藏时，也可以从那里把它重新显示出来。

**「自定义…」支持的时长格式：**

| 输入 | 含义 |
| --- | --- |
| `25` | 25 分钟（默认单位是分钟） |
| `45m`、`1.5h`、`90s` | 45 分钟、1.5 小时、90 秒 |
| `1h30m` 或 `1小时30分` | 1 小时 30 分钟 |
| `25:00` | 25 分 0 秒（分:秒） |
| `1:30:00` | 1 小时 30 分（时:分:秒） |

**倒计时进行中。** 可以在菜单里暂停、继续、加 5 分钟、按上次时长重新开始，或者停止。胶囊的颜色和进度条会显示剩余时间。

**时间到了。** 弹窗会出现，并持续显示已超时多久。勾选「完成目标」或「未完成目标」其中一项，然后选择：

- **关闭**：关掉弹窗。
- **重新计时**：按同样的时长再来一次。
- **再来 5 分钟**：延长同一个目标。不需要勾选，也不会被算作新的一次倒计时。

**每日统计。** 每个结束的倒计时都会计入今天的总数；勾选「完成目标」则计入今天的完成数。菜单里会显示类似「今日：完成 3 / 5（60%）」的一行。点 **Call it a day（收工并清零）** 会显示今天的汇总（完成数、未完成数、完成率、统计起点），确认后清零并开始新的一天。中途手动停止、没有走完的倒计时不计入。计数不会在零点自动清零，只有你点了收工才会重置。

**隐藏和显示。** 在任何地方按 **Control + Option + T**，或者用菜单。如果这个快捷键已被别的软件占用，快捷键会静默失效，但菜单依然可用。

## 卸载

如果你在菜单里开启过「开机自动启动」，请先在菜单里关闭。然后运行：

```bash
bash uninstall.sh
```

它会退出 App、从 `~/Applications` 删除，并清除保存的设置。

## 常见问题

- **安装脚本提示缺少命令行工具。** 点击弹出窗口里的「安装」，等它装完，再重新运行安装脚本。也可以自己运行 `xcode-select --install`。
- **编译报错。** 请提交 issue，附上完整的输出，以及 `sw_vers` 和 `swiftc --version` 的结果。
- **看不到胶囊。** 先按一下 Control + Option + T，它可能被隐藏了；然后点菜单栏图标，选「把胶囊移回右上角」。
- **在 /Applications 里找不到 App。** 它只为当前用户安装，位置是 `~/Applications`（Finder 里：前往 > 个人 > Applications）。也可以用 Spotlight 搜索，或者自己把它移到 `/Applications`。
- **「开机自动启动」设置失败。** 请在「系统设置 > 通用 > 登录项」里手动添加这个 App。

## 说明和限制

- 退出 App 会丢掉正在进行的倒计时；设置和每日统计会保留。
- 胶囊会出现在所有桌面和全屏 App 之上，但它是普通窗口，所以会出现在录屏和屏幕共享里。共享屏幕之前，请先按 Control + Option + T 把它隐藏。
- `src/en/main.swift` 和 `src/zh/main.swift` 的代码相同，只有界面文字不同。修改其中一个时，请同步修改另一个。
